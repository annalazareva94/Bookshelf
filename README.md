# Bookshelf (Tier List) — Frontend

Веб-интерфейс приложения **Bookshelf** — сервиса для составления tier-листов книг.
Написан на Vue 3 + TypeScript. Общается с отдельно развёрнутым бэкендом (FastAPI) через REST API.

## Стек

- **Vue 3** — Composition API, `<script setup>`
- **TypeScript**
- **Pinia** — управление состоянием
- **Vue Router** — маршрутизация
- **Vite** — сборка и dev-сервер
- **Fetch API** — запросы к бэкенду (в dev-режиме через прокси Vite)

## Требования

- **Node.js** — версия 20.x (проверено на 20.20.2)
- **npm** — идёт вместе с Node.js


## Установка и запуск

# 1. Установить зависимости
npm install

# 2. Запустить dev-сервер
npm run dev

После запуска приложение будет доступно по адресу, который выведет Vite (обычно `http://localhost:5173`).

> ⚠️ **Бэкенд должен быть запущен отдельно** на `http://127.0.0.1:8000`. В dev-режиме запросы к `/api/*` проксируются на бэкенд (см. `vite.config.ts`). Без работающего бэкенда авторизация и загрузка данных работать не будут.

## Сборка для продакшена

```bash
npm run build
```

## Деплой

Деплой автоматический — **при пуше в `main` / `master`** запускается GitHub Actions workflow (`.github/workflows/deploy.yml`).
